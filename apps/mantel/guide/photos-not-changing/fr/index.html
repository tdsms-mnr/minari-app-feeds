Le widget photo ne change pas ? Que vérifier sur iPhone

Vous avez choisi plusieurs photos, mais le widget affiche toujours la même. Le plus souvent, c’est l’un de ces quatre réglages.

Voici ce qu’il faut vérifier dans Mantel, une app de widget photo pour iPhone.

1. L’album ne contient qu’une photo

Le widget passe à la photo suivante de l’album. Avec une seule photo, il n’y a rien à changer. Ouvrez l’album et touchez Ajouter pour en ajouter deux ou plus.

2. L’intervalle est plus long que vous ne le pensez

Dans l’album, « Changer toutes les » détermine à quelle fréquence la photo change.

  • Gratuit : toutes les heures
  • Pro : toutes les 15 minutes, toutes les heures, toutes les 6 heures ou une fois par jour

Si le réglage est sur « Une fois par jour », la photo ne change qu’une fois par jour.

3. Le widget affiche un autre album

Chaque widget affiche un album. Touchez longuement le widget, touchez Modifier le widget, puis vérifiez le réglage Album. Si aucun n’est choisi, il affiche votre premier album.

4. Un widget moyen ou grand affiche un cadenas

Les widgets moyen et grand font partie de Mantel Pro. En version gratuite, utilisez le petit widget.

Questions

À quelle fréquence la photo change-t-elle ?Toutes les heures en version gratuite. Avec Mantel Pro, choisissez toutes les 15 minutes, toutes les heures, toutes les 6 heures ou une fois par jour dans « Changer toutes les ».
Les photos peuvent-elles s’afficher dans un ordre aléatoire ?Oui, avec Pro : activez « Aléatoire » dans l’album.
J’ai ajouté des photos, mais le widget affiche toujours les anciennes.Vérifiez que le widget affiche l’album où vous les avez ajoutées : touchez longuement le widget, touchez « Modifier le widget » et choisissez l’Album.
Ça ne change toujours pas.Dans Mantel, allez dans Réglages → « Contact / signaler un problème » pour envoyer un e-mail. La version de l’app, la version d’iOS et le modèle d’iPhone sont remplis pour vous.
