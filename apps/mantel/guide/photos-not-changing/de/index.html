Foto-Widget wechselt nicht? Das kannst du auf dem iPhone prüfen

Du hast mehrere Fotos ausgewählt, aber das Widget zeigt immer dasselbe. Meist liegt es an einer von vier Einstellungen.

Das kannst du in Mantel, einer Foto-Widget-App fürs iPhone, prüfen.

1. Das Set hat nur ein Foto

Das Widget wechselt zum nächsten Foto im Set. Bei einem Set mit nur einem Foto gibt es nichts zu wechseln. Öffne das Set und tippe auf Hinzufügen und füge zwei oder mehr Fotos hinzu.

2. Das Wechselintervall ist länger als gedacht

Im Set legt „Wechseln alle“ fest, wie oft das Foto wechselt.

  • Gratis: jede Stunde
  • Pro: alle 15 Minuten, jede Stunde, alle 6 Stunden oder einmal am Tag

Steht es auf „Einmal am Tag“, wechselt das Foto nur einmal am Tag.

3. Das Widget zeigt ein anderes Set

Jedes Widget zeigt ein Set. Halte das Widget gedrückt, tippe auf Widget bearbeiten, dann prüfe das Feld Set. Ist keins ausgewählt, zeigt es dein erstes Set.

4. Ein mittleres oder großes Widget zeigt ein Schloss

Mittlere und große Widgets gehören zu Mantel Pro. Nutze in der Gratis-Version das kleine Widget.

Fragen

Können die Fotos in zufälliger Reihenfolge kommen?Ja, mit Pro: Schalte im Set „Zufällig“ ein.
