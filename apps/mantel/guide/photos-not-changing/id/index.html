Widget foto tidak berganti? Yang perlu dicek di iPhone

Kamu sudah memilih beberapa foto, tapi widget terus menampilkan foto yang sama. Biasanya penyebabnya salah satu dari empat pengaturan.

Ini yang perlu dicek di Mantel, app widget foto untuk iPhone.

1. Set hanya berisi satu foto

Widget berpindah ke foto berikutnya di set. Set dengan satu foto tidak punya foto lain untuk ditampilkan. Buka set dan ketuk Tambah untuk menambahkan dua foto atau lebih.

2. Interval pergantian lebih lama dari dugaanmu

Di set, “Ganti setiap” menentukan seberapa sering foto berganti.

  • Gratis: tiap jam
  • Pro: tiap 15 menit, tiap jam, tiap 6 jam, atau sehari sekali

Jika diatur ke “Sehari sekali”, foto hanya berganti sekali sehari.

3. Widget menampilkan set lain

Setiap widget menampilkan satu set. Sentuh dan tahan widget, ketuk Edit Widget, lalu cek Set. Jika belum ada yang dipilih, widget menampilkan set pertamamu.

4. Widget Sedang atau Besar menampilkan gembok

Widget Sedang dan Besar adalah bagian dari Mantel Pro. Di versi gratis, gunakan widget Kecil.

Pertanyaan

Seberapa sering fotonya berganti?Tiap jam di versi gratis. Dengan Mantel Pro, pilih tiap 15 menit, tiap jam, tiap 6 jam, atau sehari sekali di “Ganti setiap”.
Bisakah foto muncul dalam urutan acak?Bisa, dengan Pro: aktifkan “Acak” di set.
Saya sudah menambah foto, tapi widget masih menampilkan yang lama.Pastikan widget menampilkan set tempat kamu menambahkan foto: sentuh dan tahan widget, ketuk Edit Widget, lalu pilih Set-nya.
Masih tidak berganti.Di Mantel, buka Pengaturan → “Kontak / laporkan masalah” untuk mengirim email. Versi app, versi iOS, dan model iPhone sudah terisi otomatis.
