iPhone 위젯에 업무 캘린더만 보이게 하는 방법

iPhone에 업무 캘린더와 개인 캘린더가 함께 있으면, 모든 것을 보여 주는 위젯은 금방 복잡해져요. 업무 캘린더만 보이는 위젯이라면 업무의 다음 일정만 딱 보여요.

이 가이드에서는 Todayboard, 즉 iPhone에 이미 있는 캘린더를 읽는 캘린더 위젯으로 하는 방법을 소개해요. 캘린더 고르기는 한 번만 결제하는 Todayboard Pro에 포함돼요. 무료 작은 위젯은 모든 캘린더를 보여 줘요.

1. 업무 캘린더가 iPhone에 있는지 확인하기

Todayboard는 iPhone 캘린더 앱의 일정을 읽어요. 업무 캘린더가 아직 없다면:

  1. 다음으로 이동해요: 설정 → 앱 → 캘린더 → 캘린더 계정 (iOS 17에서는: 설정 → 캘린더 → 계정).
  2. 다음을 탭해요: 계정 추가 — 그리고 업무 계정을 추가해요. 예를 들면 Google 계정이에요.
  3. 다음을 켜요: 캘린더 — 그 계정에서.

2. 캘린더 접근 허용하기

Todayboard를 열고 다음을 탭해요: 계속 — 그런 다음 전체 접근을 허용해요. 접근은 읽기 전용이라 Todayboard가 일정을 고치는 일은 없어요.

실수로 거부했나요? iPhone은 다시 묻지 않아요. 설정 → 캘린더를 열고 ‘전체 접근’을 선택해요.

3. 업무 캘린더 고르기 (Pro)

  1. Todayboard 메인 화면에서 표시 카드를 찾아요.
  2. 다음을 탭해요: ‘보이는 캘린더’ — 그리고 업무 캘린더만 체크해요.
  3. 선택 사항: 다음을 켜요: ‘하루 종일 일정 숨기기’ — 생일과 공휴일이 숨겨져요. 이건 무료예요.

4. 홈 화면에 위젯 놓기

  1. 홈 화면으로 가서 앱이 흔들릴 때까지 빈 곳을 길게 눌러요.
  2. 다음을 탭해요: 편집 (왼쪽 위 모서리), 그다음 위젯 추가.
  3. 검색창에 ‘Todayboard’를 입력하고 크기를 고른 뒤 다음을 탭해요: 위젯 추가.

5. 업무용과 개인용을 다른 위젯으로 (Pro)

위젯마다 따로 캘린더를 보여 줄 수 있어요. 위젯을 길게 누르고 다음을 탭해요: 위젯 편집. 그다음 그 위젯의 캘린더를 골라요. 아무것도 고르지 않은 위젯은 앱의 ‘보이는 캘린더’ 설정을 따라요.

더 쓰고 싶다면?

Todayboard Pro는 구독이 아니라 한 번만 결제해요:

  • 보일 캘린더 고르기 — 앱 전체에도, 위젯마다도
  • 중간(오늘과 내일)·큰(최대 7일) 위젯
  • 잠금 화면 위젯

자주 묻는 질문

Google 캘린더도 보이나요?네. 설정 → 앱 → 캘린더 → 캘린더 계정 → 계정 추가에서 Google 계정을 추가하고 캘린더를 켜요. 그러면 일정이 iPhone 캘린더 앱에 나타나고, Todayboard에도 보여요. Todayboard가 직접 Google에 로그인하는 일은 없어요.
무료로도 할 수 있나요?무료 작은 위젯은 모든 캘린더의 오늘 일정을 보여 주고, ‘하루 종일 일정 숨기기’도 무료예요. 보일 캘린더 고르기는 한 번만 결제하는 Todayboard Pro에 포함돼요. 중간·큰 위젯, 잠금 화면 위젯, 내일과 앞으로 7일 보기도 Pro예요.
업무 캘린더가 목록에 없어요.Todayboard는 iPhone에 설정된 캘린더를 읽어요. 설정 → 앱 → 캘린더 → 캘린더 계정 → 계정 추가(iOS 17에서는 설정 → 캘린더 → 계정)에서 계정을 추가하고 그 계정의 캘린더를 켠 다음, Todayboard로 돌아와요.
위젯에 ‘캘린더 고르기는 Pro예요.’라고 떠요.Pro 없이 ‘위젯 편집’에서 캘린더를 골랐기 때문이에요. ‘위젯 편집’에서 선택을 지우면 다시 모든 캘린더가 보여요. 또는 Todayboard Pro를 구입해요.
Todayboard가 일정을 바꾸거나 업로드하나요?아니요. 캘린더 접근은 읽기 전용이고, 기기 밖으로 아무것도 보내지 않아요.
